# 🍦 Ice Cream Website

## Project Overview

A multi-page ice cream e-commerce website developed as a group assignment for the **Web Fundamentals** course at Sunway University.

This project focuses on applying fundamental frontend web development concepts using **HTML, CSS, and JavaScript** to create an interactive online shopping experience.

## Website Features

- **Home Page:** Homepage showcasing ice cream products.
- **Shop:** Product listings and browsing pages.
- **Product Details:** Individual pages displaying product information.
- **Shopping Cart:** Cart interface for selected products.
- **User Account:** Login and sign-up interfaces.
- **Additional Pages:** About Us, Blog, and Contact pages.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Webpage structure and content |
| CSS3 | Styling, layouts, and visual design |
| JavaScript | Client-side interactivity and DOM manipulation |

## Running the Website Locally

1. Clone or download this repository.
2. Open the project folder.
3. Navigate to `index.html`.
4. Open the file in a web browser.

## Project Structure

- `html/` — Website pages
- `css/` — Stylesheets
- `js/` — JavaScript functionality
- `media/` — Images and other website assets
